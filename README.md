# CSS 선택자 던전

CSS 선택자를 연습하는 픽셀 RPG 게임입니다. 까딱거리는 물건을 고르는 선택자를 입력하면, 물건이 인벤토리로 날아가고 흰 고양이 모험가가 장비를 하나씩 갖춰 입습니다.

웹과 모바일 홈페이지의 이해와 제작 수업 자료

## 플레이 방법

1. 게임판에서 까딱거리는 물건을 확인합니다.
2. 왼쪽 아래 HTML 코드(`dungeon.html`)에서 그 물건의 태그 구조를 읽습니다.
3. 오른쪽 CSS 에디터(`style.css`)에 까딱거리는 물건만 정확히 고르는 선택자를 입력하고 `확인`(또는 Enter)을 누릅니다.
4. 설명 탭과 선택자 도감을 참고할 수 있습니다. 도감 카드를 누르면 해당 선택자 설명이 열립니다.

## 구성

- 1~17번: 기본 모드. 선택자를 하나씩 배웁니다.
- 18~25번: 챌린지 모드. 배운 선택자를 조합해 스스로 해결합니다.

| 도감 카드 | 선택자 |
|---|---|
| 태그 선택자 | `태그이름` |
| 전체 선택자 | `*`, `A *` |
| 아이디 선택자 | `#아이디` |
| 클래스 선택자 | `.클래스`, `태그.클래스`, `.클래스1.클래스2` |
| 자손/자식 선택자 | `A B`, `A > B` |
| 그룹 선택자 | `A, B` |
| 형제 선택자 | `A + B`, `A ~ B` |
| 속성 선택자 | `[속성]`, `[속성="값"]` |
| 가상 클래스 | `A :first-child`, `A :nth-child(n)`, `A:not(B)` |

## 실행

`index.html` 파일 하나로 동작합니다. 파일을 브라우저로 열거나 GitHub Pages로 배포하면 됩니다.

## 레벨 수정

`index.html`의 `<script>` 안 `LEVELS` 목록을 고치면 됩니다. 레벨마다 아래 값이 들어 있고, 게임판·HTML 뷰어·설명 탭은 여기서 자동으로 만들어집니다.

- `card`: 연결된 도감 카드 번호 (챌린지는 `null`)
- `name`, `syntax`, `desc`, `examples`: 설명 탭에 보이는 내용
- `answer`: 까딱거릴 물건을 정하는 모범 답 (학생 답은 같은 물건을 고르면 모두 정답)
- `html`: 게임판에 놓일 태그 구조
- `challenge: true`: 챌린지 모드 레벨

## 교사용 테스트

`Ctrl + Shift + D`(맥은 `Cmd + Shift + D`)를 누르면 오른쪽에 레벨 이동 버튼이 나타납니다. 다시 누르면 숨겨집니다.

## 사용 기술

HTML, CSS, JavaScript만 사용했습니다. 픽셀 그림은 SVG로 코드에 들어 있고, 효과음은 Web Audio API로 만듭니다. 글꼴은 KoPub World 돋움(jsDelivr)을 불러옵니다.
